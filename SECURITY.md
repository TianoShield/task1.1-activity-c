# Security Policy


## Reporting a vulnerability in TianoPoC itself

If you find a security issue in this repository's own code — e.g. leaked
credentials, unsafe handling of LLM output, a way for the pipeline to
execute unintended code, or a way to exfiltrate data through the pipeline —
please report it privately rather than opening a public issue:

- **Preferred:** GitHub's private vulnerability reporting (Security tab →
  "Report a vulnerability") on this repository.


## If you discover a NEW, undisclosed EDK2/HBFAplus vulnerability

This repository is not the right place to report it. Do not open an issue
or PR containing details of an undisclosed vulnerability here. Instead,
report it through TianoCore's own security process.
